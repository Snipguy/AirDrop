# 📡 AirDrop LAN - برنامه اشتراک گذاری فایل Flask

یک برنامه سبک اشتراک گذاری فایل و متن در شبکه محلی (LAN) به سبک AirDrop که با **Flask + Socket.IO** ساخته شده است.

فایل‌ها و پیام‌ها را بین دستگاه‌های موجود در یک شبکه با یک رابط کاربری مدرن و تمیز و پشتیبانی از PWA به اشتراک بگذارید.

---

## 🚀 ویژگی‌ها

- 🔐 ورود با محافظت پین
-  تعین ارسال فوری پیام‌های متنی
- 📂 آپلود فایل با کشیدن و رها کردن (Drag & Drop)
- 📊 آپلود فایل‌های تکه تکه (پشتیبانی از فایل‌های حجیم)
- ⚡ پیگیری پیشرفت در لحظه
- 🌗 حالت تاریک / روشن
- 📲 پشتیبانی از نصب PWA
- 🔊 صدای اتمام آپلود
- ☕ امکان ادغام بنر حمایت مالی (اختیاری)

## ⚙ نصب

### ۱) شبیه‌سازی مخزن (Repository)
```bash
git clone https://github.com/snipguy/LAN_AirDrop.git
cd LAN_AirDrop
```

### ۲) ایجاد محیط مجازی (توصیه می‌شود)

```bash
python -m venv venv
source venv/bin/activate  # مک/لینوکس
venv\Scripts\activate     # ویندوز
```

### ۳) نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```
اگر نمی‌توانید به PyPI اصلی دسترسی داشته باشید، می‌توانید از سرورهای پشتیبان مگان استفاده کنید:

```bash
pip install -r requirements.txt --index-url https://hub.megan.ir/pypi/simple
```
▶ اجرای برنامه

```bash
python main.py
```
سپس باز کنید:

http://127.0.0.1:5000

http://airdrop.local:5000

برای دسترسی از دستگاهی دیگر در شبکه محلی (LAN):

http://YOUR_LOCAL_IP:5000

http://airdrop.local:5000

📲 پشتیبانی از PWA

برای فعال کردن PWA قابل نصب:

برنامه باید از طریق HTTPS (یا localhost) ارائه شود.

manifest.json باید پیکربندی شود.

Service worker باید ثبت شود.
